Git 练习 · 交互式教程

一个新手友好的 Git 交互式入门教程，通过可视化「四个区域」帮助理解 Git 的工作原理。

  • 在线体验：https://kingdream-cn.github.io/git-practice/
  • GitHub 仓库：https://github.com/kingdream-cn/git-practice

功能特点

  • 四个区域实时可视化：工作区 / 暂存区 / 本地仓库 / 远程仓库
  • 模拟终端，支持 21 个 git 命令与辅助命令
  • 命令补全、命令历史、箭头动画
  • 8 章 34 张教程卡片，从基础到进阶
  • 进度保存到 localStorage，刷新不丢失
  • 零依赖，纯 HTML / CSS / JS

技术栈

  • 纯 HTML / CSS / JavaScript，无框架、无构建工具
  • Google Fonts（Inter + JetBrains Mono）
  • SVG 箭头动画
  • localStorage 持久化
